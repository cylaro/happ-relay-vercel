# happ-relay-vercel

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https%3A%2F%2Fgithub.com%2Fcylaro%2Fhapp-relay-vercel)

**Релей подписки на Vercel: подключайте сколько угодно устройств к панели с лимитом HWID — панель видит ровно одно устройство.**

[README in English](README.md)

## Почему это нужно

Панели вроде [Remnawave](https://docs.rw/features/hwid-device-limit) считают уникальные значения заголовка `x-hwid` на пользователя, а каждое приложение генерирует своё значение. Десять устройств превращаются в десять «устройств» и упираются в лимит. Значение формирует клиент и не меняется в приложении — но можно изменить **точку подключения**:

```
Телефон 1 ─┐
Телефон 2 ─┤   https://ваш-домен.tld/<секрет>/s/<токен>
Ноутбук  ─┤              │
ТВ       ─┘              ▼  фиксированная идентичность: один x-hwid, один User-Agent
                 Vercel Function (ваш)
                        │
                        ▼
                 Панель ──> видит ровно ОДНО устройство
```

Приложения работают как обычно — релей это обычный HTTPS-адрес, возвращающий подписку с вашей идентичностью.

## Развёртывание

### 1. Деплой на Vercel

Нажмите кнопку **Deploy** выше, или [vercel.com/new](https://vercel.com/new) → импортируйте этот репозиторий (Framework Preset: **Other**) → **Deploy**.

### 2. Задайте переменные окружения

Проект → **Settings** → **Environment Variables** → добавьте:

| Имя | Пример | Обязательна |
|---|---|---|
| `PANEL_BASE` | `https://panel-provider.com/sub` | да (https, без токена) |
| `HWID` | `UE42LJXu4DbiCaBv` | да (10–64 символа `A-Z a-z 0-9 = -`) |
| `USER_AGENT` | `Happ/1.16.0 (iOS 18.3; iPhone 14 Pro)` | да |
| `DEVICE_OS` | `iOS` | опционально |
| `VER_OS` | `18.3` | опционально |
| `DEVICE_MODEL` | `iPhone 14 Pro` | опционально |

После изменения переменных: **Deployments** → последний деплой → **⋯ → Redeploy** — переменные применяются только к новым деплоям.

### 3. Смените секретный префикс

Откройте [`vercel.json`](vercel.json) и замените `vx42Kq9m` в обоих маршрутах на свою случайную строку (8+ символов). Префикс — часть ссылки подписки, он защищает её от чужих людей.

### 4. Привяжите домен

Проект → **Settings → Domains** → **Add** → ваш домен.

> **Используйте свой домен с A-записью (`216.198.79.1`), режим DNS only — не дефолтный `*.vercel.app`.**
> Дефолтный домен `vercel.app` недоступен из некоторых сетей (в частности, у российских провайдеров), а облачные прокси (Cloudflare в режиме Proxied) добавляют AAAA-запись (IPv6), из-за которой приложения без фоллбэка на IPv4 висят по таймауту. A-запись в режиме DNS only делает домен доступным отовсюду.

Cloudflare как DNS: зона → **DNS → Records** → A-запись `@` (или поддомен) → `216.198.79.1` → **DNS only** (серое облако).

## Использование

```text
Проверка:  https://ваш-домен.tld/<секрет>/health
Подписка:  https://ваш-домен.tld/<секрет>/s/<ваш-токен-подписки>
```

Добавьте эту ссылку в любой клиент (Happ, v2RayTun, Streisand, Karing, …). Все устройства с этой ссылкой считаются на панели **одним устройством**, обновления работают нормально.

Проверить идентичность до подключения устройств можно вкладкой Request проекта [happ-decryptor](https://github.com/cylaro/happ-decryptor): отправьте URL панели с теми же заголовками и посмотрите ответ.

## Примечания

- Токен подписки остаётся в ссылке на устройстве; адрес панели не покидает конфигурацию.
- Не публикуйте ссылку: любой, у кого она есть, расходует ваш трафик под вашей идентичностью.
- Цель `PANEL_BASE` должна быть доступна из сети Vercel (часть провайдеров блокирует IP дата-центров — если панель возвращает пустой ответ, проверьте её напрямую).
- Бесплатного плана Vercel Hobby достаточно для личного использования.
